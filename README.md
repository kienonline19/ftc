sửa `Config.java` sang sân DECODE (mục 0.4 của tài liệu).

**Xem tài liệu có hình:** mở thư mục này bằng VS Code, mở file `.md` rồi bấm `Ctrl+Shift+V`. Ba sơ đồ máy trạng thái
(Mermaid, mục 2.7, 4.4 và 5.1) cần thêm tiện ích *Markdown Preview Mermaid Support*. Cách khác: đẩy cả thư mục lên
GitHub, GitHub hiển thị sẵn hình, bảng, sơ đồ Mermaid và các khối *Lời giải* thu gọn.

Bản này bao gồm và thay thế bộ "Motor & Cảm biến · Pedro Pathing" trước đó: Phần 1–2 giữ nguyên nội dung, có thêm
liên kết sang Phần 3–5.
